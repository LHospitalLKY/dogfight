# 空战狗斗模拟器

基于 Python 的 1v1 空战对抗模拟：6DOF / 3DOF / 2DOF 动力学内核 + 四层战术 Agent + three.js 浏览器 3D 可视化。
目标是研究**机体性能参数如何影响超视距（BVR）与近距格斗（WVR）的战术选择**，而不是做一个飞行模拟器。

唯一可视化入口是浏览器里的 three.js 观战端（实时 3D、可交互相机、1080p 采集）；主程序本身只用终端输出过程与结果。

当前版本：**1.1.1**（构建方式见[构建发行版](#构建发行版)）。

## 功能

### 动力学内核

- 默认 6DOF 刚体，可一键切到 3DOF / 2DOF 做对照实验；物理步进 120 Hz，Agent 决策 10 Hz。
- ISA 标准大气（0–32 km），密度同时作用于升力、诱导阻力与推力；推力按 `(ρ/ρ₀)^n` 衰减（指数按机型标定：Su-57 0.65、F-16V 0.90），再叠加冲压恢复、高空推力悬崖与安装损失；阻力含跨声速/超声速波阻，速度由推力/阻力平衡自然决定。
- 军推 / 加力两档推力，对应不同单位耗油率（加力约为军推的 3 倍）；油量不足按剩余燃油等比降推，油尽禁止加力。开局速度取机型巡航马赫并反解巡航油门。
- 主动减速：减速板/差动舵面按等效零升阻力增量建模（全开 `BRAKE_CD=0.08`），用于低速大迎角段快速压速度（钟摆拉起后收油+开减速板就是靠它把速度压到零附近）。
- 质量实时联动：导弹发射后推力、翼载、失速速度、比剩余功率、可用过载、转动惯量都按当前质量重算。
- Su-57 的 3D 矢量喷口（6DOF 专属）：喷口偏转同时提供俯仰与偏航力矩（近零速段方向舵没有动压，偏航只能靠三元矢量），并可在过顶动作中维持 55° 过失速迎角；除过失速操纵与 COBRA 外，喷流还带来随油门/加力开度缩放的等效增升（CL +0.30），把盘旋可用升力上限从 CL≈1.50 抬到 ≈1.80，低速段最小回旋半径明显小于常规喷口机型。
- 能量-高度联合约束：爬升角受 Ps 限制、过载上限随当地失速速度调整、能量天花板触发强制卸载。
- 飞行员过载耐受模型：持续 6 g / 峰值 9 g，疲劳累积到阈值触发 G-LOC 失能。

### 感知层（传感器与接触等级）

- 接触质量分四级：`CONTACT_NONE=0` 无接触、`CONTACT_DETECT=1` 仅探测/告警（只有方位、没有距离）、`CONTACT_TRACK=2` 稳定跟踪（有距离与角度）、`CONTACT_FIRE=3` 火控级（只有本机机头雷达开机照射才能给出）。
- 分向 RCS：Su-57 前 0.3 / 侧 1.2 / 后 2.5 m²，F-16V 前 1.2 / 侧 3.0 / 后 2.0 m²。目标机头方位 60° 内取前向值、120° 外取后向值，中间线性过渡，避免方位抖动导致探测距离跳变。
- 隐身收益：探测距离按 RCS 的四次方根缩放。同一部 70 km@1 m² 的雷达，对 1.2 m²（F-16V 前向）约 73 km、对 0.3 m²（Su-57 前向）约 52 km；但 Su-57 尾后 2.5 m² 会被放大到约 88 km。隐身只在前向有效，迎头时谁先被发现取决于双方机头朝向与雷达开机策略。
- 机头雷达探测距离 = `radar_range × RCS^0.25 × 多普勒可见度`：Su-57 160 km@1 m²、F-16V 70 km@1 m²；火控锥取 SARH 照射锥，探测锥 ±90°。
- Su-57 侧阵相对机头 ±35°–145°，探测距离为主阵的 0.55 倍，只给 `TRACK`；L 波段襟翼雷达 ±45°、200 km，只给 `DETECT`。
- IRST：Su-57 60 km（±30°，目标开加力时 ×1.5）；F-16V 无内置 IRST，靠 Legion 级光电吊舱被动跟踪 45 km。两者都只给 `TRACK`。
- 目视 tally：迎头/尾后 9 km、侧向 11 km，全向且不受 RCS 影响；没有 tally 时机炮仍可开火，但只允许 600 m 内、散布 ×2.5。
- 预警机 400 km@1 m²（按目标分向 RCS 与全向基准中较大者做四次方根缩放、每帧连续更新），只给 `TRACK`、不能当火控；默认开启，`--no-awacs` 关闭。RWR 只在本机落入对方机头雷达火控锥时告警，只给方位、没有距离。
- 火控门槛：中距弹要求雷达开机且 `CONTACT_FIRE`。静默（雷达关机）或只有 IRST/吊舱/预警机/侧阵的 `TRACK` 时，都拿不到火控诸元，不能发射雷达弹。

### 战术 Agent

- 四层架构：几何态势判定 → 战术族选择 → 机动原语执行 → 控制层（能量/过载/发射门限），所有原语最终都落到滚转角 + 过载指令上。
- 35 种机动原语：纯追踪、提前量追逐、滞后追逐、单环/双环/急转、破 S（含横偏 `DIVE_OFFSET` 与偏转 `DIVE_BREAK` 变体）、防御滚筒、剪刀、内筋斗、殷麦曼、高/低悠悠、赫布斯特（`HERBST`）、克沃丘尔钟摆（前倒 `KVOCHUR_BELL` / 后倒 `KVOCHUR_BELL_BACK`）、脱离、卸载、改出、规避、占位、诱导先手（`LURE`）、CRANK、三九下高、F-pole、机炮提前量/压近、COBRA，以及一串高 G 变体。钟摆需要 6DOF + 矢量喷口，赫布斯特只需 6DOF，否则自动禁用。
- 开局按机体特性选择单环 / 双环抢位（瞬时转弯好的走单环、持续盘旋好的走双环），占位参数每次启动随机化。
- 开局为 120 km 对头接近（双方各距空域中心 60 km）；没有稳定跟踪时进入 `SEARCH`，朝最后已知位置或空域中心搜索，中距弹交完后由 `PRESS` 主动压近，油量/弹药见底则 `DISENGAGE` 脱离。
- 中距弹发射门限：已进 NEZ，或命中概率估计 `radar_pk_est ≥ 0.22`（约对应有效包线 0.7–0.8）即可开火；同时要求离轴 ≤20°、本机速度 >1.35 倍当地失速，且距离不超过弹载导引头的自主截获距离（否则末段前全靠载机照射，对手一横转就打断），保证弹离架后还有真实的中制导段。
- 中距弹第二发采用“围堵”纪律：首发进入末段（不再需要载机照射）、离架 ≥10 s、首发弹剩余飞行时间 ≤18 s，且对手已被逼转出 ≥45° 或被空域边界压缩（边界余量 <8 km），才从新方位补射，最多两发同时在空中。
- 防御动作按来袭弹剩余飞行时间与能量余量评分选择（远距横转耗能、近距才切高 G 硬甩），同一威胁内保持转向侧不抖动；箔条只在载机处于横转/三九姿态时才投放，红外弹另走不依赖多普勒盲区的规避池。
- 能量保护：速度低于 1.55 倍当地失速时过载压到可维持值（高 G 原语在 >1.30 时除外，避免形同普通盘旋）；近距僵持 ≥10 s 无人拿到射击窗口时触发改出族，主动重置几何。

### 武器与对抗

- 主动雷达中距弹 R-77-1 / AIM-120C：中制导依赖载机雷达照射，末段导引头自主截获（pitbull）后发射后不管；远距发射自动 loft 弹道。
- 近距弹 R-73 / AIM-9X 与机炮，锁定采用"持续留在导引头视场内累计时长"的状态机；近距弹只在目标进入不可逃逸区、离轴 ≤30° 且本机速度 >1.35 倍当地失速时发射，大离轴发射前还会先推演 1.5 s 弹道，与载机最近距离不足杀伤半径 +45 m 时放弃，避免掉头擦到自机。
- 机炮按真实外弹道：Su-57 / J-20 30 mm（初速 900 m/s、25 发/s、150 发），F-16V 20 mm（初速 1030 m/s、110 发/s、511 发）；弹丸受二次阻力与重力，线段-球命中判定，单发伤害由 `gun_dps` 归一化。扳机窗口为射程 ×0.90、半锥 15°，无目视接触时散布 ×2.5。
- 导弹横向过载指令经一阶自动驾驶仪滞后（近距弹 0.12 s、中距弹 0.18 s）建立，末段目标拉大过载会产生真实脱靶。
- 近炸引信改为概率杀伤：按脱靶量与杀伤半径给出 PK 并掷骰，允许近失而非一发必杀。
- 雷达隐身：分向 RCS 按四次方根缩放雷达探测距离与雷达弹发射包线（弹载主动截获距离按机型的全向 RCS 基准缩放）；三九横穿过零径向速度时，雷达与弹载导引头都会短暂失锁。下视时地面杂波展宽多普勒谱、等效 MDV 抬高（高差 4 km 时约 +55%），低空横穿的目标更容易借杂波藏起来。
- 制导容错：中制导失照后按惯导外推，连续超过 2 s 才转无控；末段主动导引头连续盲区 > 2 s、连续越出视场 > 1 s 才真丢锁，恢复后重新接上比例导引。
- 末段能量耗尽：动压低于 1200 Pa 后舵面压不出升力，弹转为惯性坠落；速度掉到 120 m/s 以下按失控弹处理，不再计入命中。
- 双发围堵：第二发不跟随首发弹道，只在首发进入末段且对手已被逼转向/压边时从新方位补射，形成夹击；对手始终不转就保留第二发。
- 干扰物：Su-57 为 24 箔条 + 18 热诱弹，F-16V 为 30 箔条 + 60 热诱弹；雷达弹逼近到 3.5 km 且载机横转程度 ≥0.55 才自动撒箔条，红外弹逼近到 2 km 且已确认被跟踪后双发连投热诱弹；同种投放间隔 1.5 s，诱饵有独立运动、诱骗与渲染逻辑。

### 判定与边界

- 击落：一方 HP 归零后，等仍在飞的导弹落定再结算，避免忽略后到的命中。
- 坠机/出界：低于最低高度 1500 m 判“坠机”，飞出 200 km × 200 km 空域判“飞出交战空域”；超过 30 km 验证高度只记录事件，不再判“解体”。
- 超时：按血量比例判胜；血量打平则比较军推续航（剩余燃油可维持的秒数），相差 >5 s 时续航长者胜，否则平局。

### 可视化

3D 画面只在浏览器端呈现（见下节），尾焰、导弹、箔条/热诱弹云团与航迹都是实时渲染。界面字体统一为 `assets/fonts/FiraCode-Regular.ttf`（Fira Code），数字按定宽槽位排版，读数逐帧变化时整行宽度不抖动。

### Web 观战（three.js）

`dogfight/web/server.py` 复用同一套内核，用 SSE 把 24 Hz 快照推给浏览器；three.js 为本地 vendored 文件，不依赖 CDN 与外网。

- 机体与导弹直接读取 `assets/aircraft`、`assets/missiles` 下的原始 OBJ，按真实机长/弹长归一后导出到 `dogfight/web/static/models/`；俯视轮廓与兜底模型从同一份 OBJ 体素抽稀，几何完全一致。
- 机体迷彩按物体空间三平面投影实时生成；加力尾焰、导弹弹体、箔条/热诱弹云团与燃烧拖尾都是实时特效。
- 地面为战术地图：4096² 城市贴图叠加海岸线与灯光 mask，中心 100 km 自动换成 24 m/px 精细层；底台是带平面反射的磨砂玻璃，随视角产生模糊倒影。独立地形 demo 在 `/static/terrain_demo/index.html`。
- 航迹为随滚转明暗的渐变飘带，从机尾起步并带方向箭头；导弹发射星标、高 G 机动菱形与机炮开火点保留在 3D 场景里。
- 机体旁直接标出当前 `战术族 · 机动原语`（如 `SURVIVE · DIVE_OFFSET`），在飞导弹标出型号与是否仍在制导。
- HUD 为 DOM 覆盖层：双方雷达屏、抬头显示、武器挂载页、三维姿态框与结算横幅，按窗口宽度自动重排；`SPACE` 暂停、`R` 重置、`F` 切换机尾跟拍，鼠标拖动环绕、滚轮缩放。
- HUD 布局：红方贴左上、蓝方贴右上，各由雷达屏、抬头显示仪与武器挂载页三块面板组成；窗口不够宽时三块改为竖排。面板为半透明磨砂玻璃，只用队伍色边线与顶部强调条区分归属。
- 雷达屏机头朝上，含距离环、目标光点与来袭弹红楔形；武器挂载页中央是按 OBJ 正交俯视生成的机体轮廓，左右两栏逐行给出 `READY/EMPTY`、余量、在飞弹数，底部为机炮与干扰物余量。目标颜色按火控状态统一：绿=已跟踪未锁定，黄=正在锁定（可发射），红=已锁定。
- 抬头显示：左侧速度刻度、右侧高度刻度，数值以方框滚条式变动；中央固定水平标志与俯仰梯的夹角即当前横滚；顶部航向带显示当前航向。只有方位、没有距离时（`DETECT`/RWR），航向带上用小红箭头指向对应刻度。
- 界面文字按“同一信息只出现一次”收敛：血量与过载合成 HUD 顶部状态带（左 `HP` + 血量条，右 `G`），低于 25% 血量转红；雷达屏左下角为战术态势（`SEPARATED/POSITIVE/DEFENSIVE…`），右下角红字 `IN n` 为来袭弹数；武器页页头给出导引头状态（`SEEK` / `SEEK xx%` / `LOCK`）。
- 固定分辨率采集：打开 `/?capture=1920x1080&name=j1&delay=3&frames=90&fps=30`，前端按 1920×1080 渲染并把 PNG 帧 POST 到 `/api/capture`；帧数大于 1 时服务端自动用 ffmpeg 编码成 `dogfight/web/captures/j1.mp4`。采集只合成 3D 场景，DOM 上的 HUD 不在画面内。

### 实验工具

| 命令 | 说明 |

## 仿真模拟结果

### 1. 矢量喷口的盘旋收益

测得条件：9 km、Su-57 作战重量 25300 kg、定高定速、坡度上限 80°、过载取当地可用值（升力上限与 9 g 结构限制取小），用水平航迹弧长/转角反算半径 `R = V / ψ̇`。

| V (m/s) | 有矢量 R (m) | 无矢量 R (m) | 半径变化 |
| --- | --- | --- | --- |
| 130 | 789 | 972 | −18.8% |
| 150 | 763 | 916 | −16.7% |
| 180 | 748 | 880 | −15.0% |
| 200 | 742 | 865 | −14.2% |
| 210 | 763 | 863 | −11.6% |
| 220 | 857 | 861 | −0.5% |
| 250 | 1153 | 1153 | 0 |
| 300 | 1721 | 1721 | 0 |

- 最小回旋半径 **742 m（有矢量）/ 861 m（无矢量）**，约小 14%；角点速度附近的绝对最小半径出现在 200–210 m/s。
- 220 m/s 以上两者完全重合一档：此时可用过载已经撞上 80° 坡度对应的 5.76 g 上限，矢量增升再多也换不出额外的水平转弯率。矢量推进的收益因此集中**低速、大迎角**段，与真实喷流增升的作用区间一致。
- 参数取 CL 增量 0.30；敏感性扫描显示 0.15 / 0.30 / 0.45 分别对应最小半径 828 / 742 / 667 m，0.30 是“收益明显但不破坏能量平衡”的折中。

### 2. 无头对局回归

| 实验 | 结果 |
| --- | --- |
| `--headless --seconds 300 --seed 3`（6DOF） | 共射 9 发、命中 3 发；SU-57 在 254.6 s 被击落，F-16V 余 53.3 HP 获胜。max g = 8.0，高度 8.3–11.2 km，无越界/解体 |
| `--ab-suite --seconds 300`（12 局） | 3DOF：F-16V 6 胜（6 局全部击落）；6DOF：SU-57 1 胜 / F-16V 5 胜（5 局击落、1 局超时） |
| 矢量增升开/关对照（6DOF，5 seed × 2 站位） | 开：SU-57 5 胜 4 负 1 平；关：SU-57 5 胜 4 负 1 平 |

6DOF 下胜负基本由超视距导弹交换与近距反杀决定：F-16V 在 20 km 内先敌开火、靠 AIM-120C 的命中概率与后续近距弹取得多数胜利，SU-57 只有在能把交战拖进低速大迎角缠斗时才占优（6DOF 镜像矩阵里唯一一场 SU-57 胜利即超时血量胜）。矢量增升不改变宏观胜率分布（10 局对照完全一致），它的价值体现在进入近距后的瞬时转弯与抢角速度，而不是在导弹对射阶段。

> `--ab-suite --seconds 150` 在 120 km 初始间距下还没进入发射窗口（双方 100% HP 超时），矩阵实验请用 300 s。

### 3. 感知层与制导修复对照

在同一套 16 seeds × 200 s 实验下，对比“旧制导 + 单发”与“新制导 + 双发”两种配置（初始条件均为 120 km、Su-57 M1.30 / F-16V M0.95）：

| 指标 | A：旧制导 + 单发 | B：新制导 + 双发 |
| --- | --- | --- |
| 中距弹发射（SU57 / F16） | 32 / 25 | 32 / 12 |
| 中距弹命中（SU57 / F16） | 0 / 0 | 2 / 0 |
| 累计伤害（SU57 / F16） | 0 / 0 | 117 / 0 |
| 脱靶量范围 | 0.5–2.6 km | 8–143 m |
| 击落数 | 0 | 0 |

- 制导修复把中距弹从“几乎必然脱靶”压到百米级：失锁容忍与惯导外推让弹在目标短暂横穿后还能重新接上，脱靶量从公里级降到 8–143 m。
- B 组两发命中分别出现在 seed11（56 伤害）与 seed16（62 伤害），仍未形成击落：近炸概率杀伤按脱靶量衰减后，单发伤害低于 Su-57 110 HP / F-16V 100 HP 的机体血量。
- 双发补射没有增加发射总数（A 组 32 发对应 B 组 32 发），只改变了发射节奏与在飞弹数量；F-16V 发射数从 25 降到 12，说明在 NEZ 门限下它更少做无效远射。
- 回归测试 42 passed；`test_w06_envelope_rcs_handling` 的假目标已改为真实 `Aircraft`，按分向 RCS 重新标定断言。

## 快速开始

需要 Python 3.10+（开发环境为 conda 环境 `dogfight`）。

```bash
conda create -n dogfight python=3.10 -y
conda activate dogfight
pip install pyyaml                   # 配置解析（运行时唯一第三方依赖）
pip install pillow                   # 可选：重新生成机体轮廓图

python -m dogfight                     # 终端跑一局（默认 6DOF、300 s）
python -m dogfight --headless --seconds 300
python -m dogfight --ab-suite --seconds 300

python -m dogfight.web                 # 浏览器观战：http://127.0.0.1:8765/
python -m dogfight.web --seed 3 --seconds 300   # 固定开局复现实验
```

`python main.py` 保留为等价入口（转发到 `python -m dogfight`）。

浏览器观战支持同一套参数（`--dof`、`--baseline`、`--seed`、`--seconds`、`--scenario`、`--radar-policy`、`--no-awacs`；旧的 `--f16-radar` / `--su57-radar` 仍可用）；默认每次启动随机占位，要复现某局请固定 `--seed`。浏览器内按 `SPACE` 暂停、`R` 重置、`F` 切换跟拍，鼠标拖动旋转、滚轮缩放。
