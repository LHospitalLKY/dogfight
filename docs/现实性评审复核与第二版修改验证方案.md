### 1.3 复核得到的两个额外事实

1. **报告的 Ps 表来自旧波阻模型。** 报告在 12 km、M2 给 Su-57 Ps=+3.4 m/s，要求零升阻力约 0.040（即 M2 无波阻）；HEAD 的 `drag_divergence(2.0)=0.18`，同一状态 Ps 实测为 −69.5 m/s。因此推力衰减问题不能用报告的 +44 m/s 作为标定目标，必须重新测。
2. **报告的 6DOF 推力 bug 已经在 HEAD 消失。** `_integrate_rigid` 现在直接使用 `_apply_power()` 返回值（`sim.py:1418`），并在 `1446-1448` 明确注释“不得再按 throttle×最大加力重算”。但 3DOF/6DOF 仍共用模块级 `thrust_lapse`，下一轮改推力模型时不能只改一处。

## 2. 修改方案

优先级：

- **P0**：直接决定“能不能做出垂直机动/能不能正确发射红外弹”，先修；
- **P1**：决定飞行包线是否可信（推力、升限、气动、机炮、导弹阻力）；
- **P2**：决定信息战与 BVR 是否可信（传感、RCS、雷达、裁判）；
- **P3**：统计标定、文档与长跑回归。

所有改动遵循一条硬约束：**先补判定测试，再改模型**，每项改动都有独立可复现的数值判据。

### 2.1 P0-A：解除垂直自由度的人为夹断

#### 现状与根因

- 6DOF 欧拉运动学把 `theta` 夹在 `±GAMMA_LIMIT=±80°`（`sim.py:1501-1503`）；
- 3DOF 把 `gamma` 夹在 `±80°`（`sim.py:1274, 1309`），并在 `psi_dot` 里把 `cos(gamma)` 下限抬到 0.20（`sim.py:1275`）；
- 结果 `γ=θ−α` 永远到不了 90°，筋斗、破 S、殷麦曼、垂直剪刀全部退化。

#### 修改数学

6DOF 用四元数积分姿态，避免 `θ=±90°` 的欧拉奇点：

```text
q = [w, x, y, z]
q̇ = 0.5 · q ⊗ [0, p, q, r]          # p,q,r 为机体系角速度
每步归一化 |q| = 1
```

由四元数反解显示用欧拉角（本项目 psi 从 x 轴逆时针，注意符号）：

```text
phi   = atan2(2(wx + yz), 1 − 2(x² + y²))
theta = asin(clamp(2(wy − zx), −1, 1))
psi   = −atan2(2(wz + xy), 1 − 2(y² + z²))
```

3DOF 保留 `gamma` 作为航迹角，但：

```text
gamma ∈ [−π, π]
psi_dot = g·n·sin(phi) / (v·cos(gamma))     仅当 |cos(gamma)| > 0.05
若 |cos(gamma)| ≤ 0.05 且 |sin(phi)| < 0.05：psi_dot = 0（纯垂直面内机动）
否则按符号给一个有界极限，避免 0/0
位置积分：x += v·cos(gamma)·cos(psi)·dt
          z += v·sin(gamma)·dt        # 不再把 cos(gamma) 抬到 0.20
```

`clamp` 只保留在迎角/过载/结构限制上，**不再限制姿态角本身**。低速保护仍由 `v_floor`、`N_MIN`、失速升力曲线负责。

#### 代码改动点

| 文件 | 改动 |
| --- | --- |
| `sim.py` | 新增四元数状态与积分；`_integrate_rigid` 不再 clamp theta；`_integrate_point` 放开 gamma、修 `cg` 与 `psi_dot` 奇点；`Observation`/渲染继续用派生的 `phi/theta/psi` |
| `sim.py` | `GAMMA_LIMIT` 改名为 `ATTITUDE_SOFT_LIMIT` 或删除；不要再被状态更新引用 |
| `agents.py` | `aim_action` 的角度误差用 `wrap_pi(target − current)`，否则跨 ±180° 会反向拉杆 |
| `render.py` | 若直接读 `theta` 显示，改为读取派生值，避免四元数未同步 |

#### 战术原语重写（与 P0-A 同批）

- `_loop`：改为垂直圆四阶段（目标航迹角 `γ0 + k·90°`，`k=0..3`，bank=0，n≈0.95·n_avail），累计垂直转过 360° 退出；不再用“爬到 65° 再俯冲到 −40°”冒充筋斗。
- `_immelmann`：拉起至 `γ≈+90°` → 顶点滚转 180° → 拉回 `γ≈0°`，航向反向。
- `_split_s`：滚转倒扣 → 拉杆经 `γ=−90°` 到 `γ≈0°`，高度换速度、航向反向。
- `Action.bank` 的归一化范围需要允许倒扣：3DOF 仍饱和在 ±`MAX_BANK`，6DOF 允许 `phi_cmd ∈ [−π, π]`（建议把 `Action.bank` 语义改为“以 MAX_BANK 为单位，可到 ±π/MAX_BANK”，或新增 `roll_inverted` 布尔）。

#### 验收判据

| 测试 | 判据 |
| --- | --- |
| 6DOF 筋斗 | n=9、9 km 起：`theta` 连续越过 90°/180°，无 NaN、四元数模长误差 <1e-9；高度先升后降，末高度与初值差 <300 m；航向漂移 <15° |
| 3DOF 筋斗 | `gamma` 连续越过 ±90°/±180°，航向漂移 <5°，`v` 单调下降（能量损失） |
| 殷麦曼 | 航向变化 180°±20°，高度增加 >800 m，退出 `γ` 在 ±10° 内 |
| 破 S | 航向变化 180°±20°，高度下降 >800 m，速度增加 >30 m/s |
| 回归 | 2DOF 定高盘旋仍严格 Δz=0；3DOF 45°/60° 盘旋转率误差 <5% |

### 2.3 P0-C：统一红外/雷达发射包线

#### 现状

- 锁定：红外用 `seeker_range`，不乘 RCS（`sim.py:1555-1558`）；
- 发射：所有弹都乘 `rcs_scale(foe.rcs)`（`sim.py:1637-1639`）；
- 观测：`observe()` 红外按 `seeker_range` 不缩放（`sim.py:1001`），雷达按 RCS 缩放（`sim.py:1038`）。

三处逻辑各自为政，导致“能锁不能射”。

#### 修改数学

```text
IR:    R_launch = min(mspec.max_range, mspec.seeker_range)
       （目标红外辐射只与尾向/发动机功率有关，与雷达 RCS 无关）
Radar: R_track  = radar_range_ref · (σ_eff / 1 m²)^0.25 · notch
       R_launch = min(mspec.max_range, R_track)
```

新增统一函数（lock / launch / observe 三处共用）：

```python
def launch_envelope(ac, mspec, foe) -> float:
    if mspec.is_radar:
        return min(mspec.max_range, radar_track_range(ac, foe))
    return min(mspec.max_range, mspec.seeker_range)
```

红外可选加入**尾向增益**（不是 RCS）：`R_ir = seeker_range · (1 + 0.15·(1−cos(aspect))/2)`，迎头 1.0、尾后约 1.15，量级很小，只用于体现“尾焰更热”。

#### 验收判据

| 测试 | 判据 |
| --- | --- |
| U05 | AIM-9X 对 Su-57：锁定/发射/`observe` 三处均为 12.00 km（±0.01） |
| U06 | R-73 对 F-16V：三处均为 10.00 km，不再出现 10.47 km |
| U07 | 红外包线对目标 RCS 不敏感：RCS 0.1→5 m² 时包线变化 <1% |
| U08 | 雷达包线仍随 RCS 四次方根变化：0.5 vs 1.2 m² 距离比 = (2.4)^0.25 = 1.245±0.01 |

### 2.4 P1-A：推力高度衰减与升限

#### 现状

```text
thrust_lapse(z, M) = (ρ/ρ0)^0.7 · (1 + 0.30·M)
```

两个问题：

1. 指数 0.7 < 1：定马赫下推力比阻力掉得慢，Ps 随高度不降反升；
2. 冲压项在海平面、M0 也生效，SL/M1.0 推重比虚高到 1.41。

#### 修改数学

用“密度衰减 + 冲压恢复 + 高空降额”三项，参数进 `AircraftSpec`，由标定脚本拟合：

```text
σ = ρ(z)/ρ0
ram(M,σ) = 1 + (r0 + r1·(1−σ))·M,        r0=0.16, r1=0.14, 上限 1.55
derate(z) = 1                              z ≤ z_knee
          = exp(−(z−z_knee)/H)             z > z_knee
T(z,M) = T_SL · σ^a · ram(M,σ) · derate(z) · η_install
```

- `a`：每机型一个（Su-57 起 0.78–0.85，F-16V 起 0.95–1.00）；
- `z_knee`：12–14 km；`H`：5–7 km；`η_install≈0.97`；
- 这些只是**初值**，必须由 `scripts/calibrate_thrust.py` 对下表锚点做最小二乘拟合，不允许手工拍脑袋。

#### 标定锚点（判据来源）

| 锚点 | F-16V | Su-57 |
| --- | --- | --- |
| 海平面静推力 / 作战重量 | 1.15–1.25 | 1.10–1.20 |
| 9 km、M0.9 推力 / 海平面静推力 | 0.45–0.55 | 0.45–0.55 |
| 9 km 满加力平飞最大 Mach | 1.45–1.65 | 1.50–1.70 |
| 12 km 满加力平飞最大 Mach | 1.60–1.85 | 1.70–1.95 |
| Ps_max 峰值高度 | 10–13 km | 10–13 km |
| 绝对升限（Ps_max=0） | 16.5–18.0 km | 20.0–22.0 km |
| 25 km 平飞 | 不可能（Ps<0） | 不可能（Ps<0） |

注意：绝对升限比“实用升限”（爬升率 0.5 m/s）高 1–2 km，因此 F-16V 的 16.5–18.0 km 与公开实用升限 15.2 km 并不矛盾。

#### 代码改动点

| 文件 | 改动 |
| --- | --- |
| `sim.py` | `thrust_lapse` 改为接受 `spec` 或参数；`AircraftSpec.thrust_at`、`World._apply_power` 统一走新的 `spec.thrust_lapse(z, M)`，禁止再有一个模块级全局被两处各调一次 |

#### 与“30 km 解体”规则的关系

`main.py:167` 的 `z_ceiling=30000` 和 `sim.py:2103` 的“超过高度上限解体”是旧推力模型的补丁。推力修好后：

- 删除“解体”判定，改为物理结果：高空 `Ps<0`，飞机自然掉高度；
- 保留地面/边界判定；
- 若仍需要软边界，只做“超出作战升限”事件记录，不扣 HP、不结束战斗。

### 2.5 P1-B：气动参数与升力上限对齐

#### 修改清单

1. **Su-57 展弦比 3.0 → 2.52**（`main.py:104`）。`span` 由 `sqrt(AR·S)` 自动变成 14.09 m。诱导阻力因子 `k=1/(πARe)` 增加约 19%，持续盘旋率下降 5–8%。
2. **超声速升力损失**：

```text
f_sup(M) = 1 − 0.30·smoothstep(0.90, 1.60, M)
cl_max_eff(M) = cl_max · f_sup(M)
```

M1.6 以上保留 70% 升力；同时用于 `v_stall_at`、`n_lift`、6DOF 的 `_cl_max_effective`。

3. **6DOF 线性升力上限对齐**：

```text
cl_linear = min(cl0 + cl_alpha·α, cl_max_eff(M))
```

Su-57 的 `cl_alpha` 从 3.6 提到 3.85，使 22° 失速迎角处正好到 1.6；F-16V 保持 3.6（22° 处 1.50，与其 `cl_max=1.5` 对齐）。这样 6DOF 与 3DOF 的升力上限不再是“参数没对齐”的假差异。

4. **负过载**：`N_MIN` 从 −2 改到 −3，仍受升力曲线和结构限制；不做“负 G 无限”。

5. **结构过载随状态变化**（P3 可选）：`n_struct_eff = n_struct · (1 − 0.1·fuel_frac)`，本轮不作为必做项。

### 2.6 P1-C：机炮外弹道

#### 现状

`sim.py:1593-1609`：目标在 1000 m、偏角 8° 内，当前帧直接扣 `gun_dps·dt`。没有飞行时间、提前量、重力下坠、散布。

#### 修改数学

每发弹丸一个状态，由炮口位置与载机速度合成初速：

```text
p_b(0) = p_ac + R_body · [x_muzzle, y_muzzle, z_muzzle]
v_b(0) = v_ac + u_gun · V_muzzle + 散布
dv_b/dt = −k·|v_b|·v_b − g·e_z
k = ρ(z)·C_D,b·A_b / (2·m_b)
```

- 20 mm：`m_b=0.102 kg`，`d_b=0.020 m`，`V_muzzle=1030 m/s`；
- 30 mm：`m_b=0.390 kg`，`d_b=0.030 m`，`V_muzzle=900 m/s`；
- 散布：每发角度高斯 `σ=0.003 rad`（约 0.17°），按弹种可调；
- 命中：把弹丸本步位移当线段，对目标做“线段–球”最近距离，`R_hit≈3.5 m`；
- 伤害：`damage_per_round = gun_dps / rounds_per_sec`，保持“全命中时 DPS 不变”；
- 弹丸寿命 2 s 或飞出 `1.5·gun_range` 即回收；每帧按 `rounds_per_sec·dt` 的累计小数发射，最多每帧 2 发。

#### 为什么要这样改

- 800 m、900 m/s 的飞行时间约 0.9 s；300 m/s 横穿目标在 0.9 s 内移动 270 m，8° 锥根本覆盖不了，必须提前量；
- 1 s 飞行时间的重力下坠约 4.4 m，正好是“机炮最难的部分”；
- 命中率由几何与弹道自然产生，不再靠“进锥即命中”。

#### 验收判据

| 测试 | 判据 |
| --- | --- |
| W01 | 800 m 正前方静止目标，瞄准中心：命中率 >60%，3 s 连射伤害接近 `gun_dps·3` 的 60–100% |
| W02 | 800 m、300 m/s 横穿目标，无提前量：命中率 <5%；加约 3° 提前量后 >30% |

### 2.7 P1-D：导弹阻力与速度包线

#### 现状

`sim.py:1979`：`cd = m.spec.cd0 + 0.15·cl²`，`cd0` 与马赫数无关。实测峰值 Mach：R-77-1 5.35、AIM-120C 3.84、AIM-9X 3.11、R-73 2.74，R-77-1 偏高约 30%。

#### 修改数学

```text
cd0_eff(M) = cd0 · (1 + w·smoothstep(0.85, 1.15, M))
```

- 中距弹 `w≈0.35–0.60`，红外弹 `w≈0.30`；
- 用峰值 Mach 与最大射程两个锚点联合标定，不单独拍 `w`。

#### 验收判据

| 测试 | 判据 |
| --- | --- |
| W06 | 峰值 Mach：R-77-1 3.6–4.2、AIM-120C 3.6–4.2、AIM-9X 2.5–3.0、R-73 2.4–2.8 |
| W07 | 9 km 迎头最大射程变化在公开值 ±15% 内；R-77-1 不再在 60 km“能量耗尽失控” |
| W08 | 同一发射条件下，阻力改版前后弹道时间变化 <10%，避免把阻力修正变成射程重标定 |

### 2.8 P2：传感、RCS、雷达与“全知观测”

#### 现状

- `rcs` 标量（各向同性）；
- 雷达距离两机都是 35 km；
- `observe()` 返回真值；
- 没有探测概率、跟踪质量、数据链延迟、敌我识别。

#### 修改方案

1. **各向异性 RCS**：给 `AircraftSpec` 增加 `rcs_front / rcs_side / rcs_rear`，按目标机头与视线的夹角 `θ` 插值：

```text
σ(θ) = σ_f + (σ_s − σ_f)·sin²θ + (σ_r − σ_s)·((1−cosθ)/2)²
```

起点：Su-57 `0.5 / 2.0 / 5.0`，F-16V `1.2 / 4.0 / 6.0`。`θ=0` 迎头、`θ=90°` 侧向、`θ=180°` 尾后。

2. **雷达探测距离独立于导弹**：

```text
R_det = radar_range_ref · (σ_eff/1 m²)^0.25 · notch
radar_range_ref: Su-57 250 km, F-16V 150 km（对 1 m²）
```

导弹的 `seeker_range=35 km` 仍可作为“数据链/发射授权距离”，但不再是雷达探测距离。`_try_launch` 的上限取 `min(missile.max_range, R_det)`。

3. **多普勒陷波/横转**：目标相对雷达的径向速度 `|v_r|` 低于门限时，雷达看不清：

```text
notch = smoothstep(20, 80, |v_r|)      # 0 ≈ 完全陷波，1 = 正常
σ_eff = σ(θ) · (0.1 + 0.9·notch)
```

这让“三九/横转”第一次有真实的收益，而不是只对箔条有效。

4. **跟踪质量与观测误差**：

```text
q = clamp(1 − (R/R_det)², 0, 1) · notch
lock_time_eff = lock_time / max(q, 0.1)
σ_R = 0.02·R / max(q, 0.2)
σ_angle = 0.5°/max(q, 0.2)
```

`Observation` 增加 `foe_detected`、`track_quality`、`last_seen_age`、`est_pos_error`；未跟踪时返回记忆外推，误差按 `0.5·a_max·t²` 增长。

5. **保留“完美观测”开关**：

```python
World(..., sensor_model="perfect" | "realistic")
```

`perfect` 用于与旧战术 AI 做 A/B，`realistic` 为默认。这样传感改造不会把旧实验全部作废。

#### 验收判据

| 测试 | 判据 |
| --- | --- |
| W09 | RCS 0.5 vs 1.2 m²：迎头探测距离比 = 1.245±0.02 |
| W10 | Su-57 迎头/侧向/尾后探测距离比 ≈ 1 : 1.41 : 1.78（按 σ^0.25） |
| W11 | 正侧方、径向速度 <20 m/s：2 s 内跟踪质量降到 0.1 以下；偏 30° 后保持 >0.5 |
| W12 | AIM-9X 包线不受 RCS 影响；R-77-1 发射上限由 80 km 与雷达距离的较小值决定 |
| W13 | `sensor_model="perfect"` 下旧战术 AI 的 10 场镜像胜率与改造前差 <10 个百分点（回归） |

### 2.9 P2：裁判规则

- 删除“z≥30 km 解体”（`sim.py:2103`）；
- 高度上限只作为“作战升限”事件记录，物理上由 `Ps<0` 自然下降；
- 保留地面/边界结束条件；
- 新增测试：F-16V 以 M2 拉起到 28 km 后 60 s 内自然掉回 20 km 以下，不触发击杀。

## 5. 风险与回滚

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 放开姿态角后 AI 意外进入筋斗/失速 | 对局失控、频繁坠地 | 只在物理层放开；AI 层保留 `gamma/altitude` 保护；先跑 100 场回归看坠地率 |
| 推力重标定使所有旧包线数字失效 | 旧报告不可比 | 结果目录升级为 `validation_v2`，旧目录保留；summary 里并列新旧锚点 |
| 机炮改成弹丸后命中率骤降 | 近距战打不死 | 用 W01–W03 标定散布与命中半径，保持“全命中 DPS”不变 |
| 雷达距离提到 150–250 km | BVR 提前、WVR 场景变少 | 增加 `radar_scale` 场景参数；默认值按公开量级，实验可调 |
| 传感不确定性使旧 AI 胜率剧变 | 战术结论不可比 | 保留 `sensor_model="perfect"`，A/B 报告差异 |
| 四元数替换引入渲染/观测回归 | 姿态显示错误 | 四元数只做积分，欧拉角仍作为派生量；I01 检查模长与连续性 |

## 6. 本轮不纳入

- 大气湍流、风切变、结冰、气动弹性；
- 6DOF 气动数据库/风洞表（仍用线性+失速衰减）；
- 地形遮蔽、雷达地平线、多路径；
- 红外背景/地物杂波、双色导引头；
- 数据链延迟、敌我识别、协同编队；
- 飞行员生理（G-LOC 已有简化，不在本轮扩展）；
- 真实发动机台架数据标定（本轮只用公开量级锚点）。

这些属于“再上一级现实性”的工作，应该在 P0–P2 的骨架稳定后再做，否则标定对象本身还在变。
