# 验证思路与飞行包线测试方案

本文针对《仿真模型与战术设计》评审意见，给出可执行的验证路线。目标不是证明模型“真实”，而是把三类问题分开：

1. **实现核查**：代码是否按文档公式计算；
2. **数值误差评估**：离散步长、限幅和保护是否改变结论；
3. **模型有效性**：模型在其声明用途内是否有独立证据支持。

测试结果应表述为“该实现、该参数、该规则下的包线”，而不是真实机型性能或真实战术优劣。

---

## 1. 验证框架与基础设施

### 1.1 三类证据不能互相替代

| 证据类型 | 回答的问题 | 本项目的典型手段 |
| --- | --- | --- |
| 代码核查 | 变量、单位、符号是否与文档一致 | 单元测试、量纲检查、坐标往返 |
| 数值验证 | 步长减半后关键指标是否稳定 | dt = 1/60、1/120、1/240 对比 |
| 模型验证 | 结果是否足以代表现实对象 | 公开数据/独立模型对照、包线定性趋势 |
| 统计验证 | 单次结果是否具有代表性 | 蒙特卡洛、置信区间、因子实验 |

固定随机种子只解决“可复现”，不解决“正确”和“有代表性”。

### 1.2 测试基础设施

现有程序需要增加最小的可观测与可驱动能力，才能做包线测试：

- **脚本化控制**：绕过 `TacticalAgent`，直接给 `Action(bank, n, throttle, ab, fire, launch_ir, launch_radar)`，用于定常盘旋、加速、爬升等开环测试。
- **全状态记录**：以物理步长输出 CSV/Parquet，至少包含：
  `t, x,y,z, psi,gamma,v, phi,theta, u,vb,wb,p,q,r, mass, fuel, throttle, ab, n, alpha, beta, qbar, T, D, L, Ps, damage, missiles_in_flight`。
- **事件日志**：锁定、发射、丢锁、诱骗、引信起爆、越界、G-LOC，各带时间戳与因果字段。
- **确定性回放**：同一配置跑两次，状态序列逐位一致；所有随机源（开局占位、引信、诱骗）由 episode seed 派生。
- **批量运行器**：`run_case(config) -> metrics`，支持参数扫描、并行和结果落盘。
- **绘图与报表**：自动生成 `h-V` 包线图、`Ps` 等值线、盘旋性能图、导弹发射包线图、Pk 校准图。

建议目录：

```
tests/unit/            公式与单位测试
tests/invariants/      能量、质量、坐标、限幅
scripts/envelope_air.py
scripts/envelope_missile.py
analysis/plots/        自动生成的包线与残差图
```

### 1.3 通用通过标准

| 项目 | 建议判据 |
| --- | --- |
| 数值健全性 | 无 NaN/Inf；无非物理负质量、负油量；角度连续 |
| 定常状态漂移 | 60 s 内高度漂移 < 50 m、速度漂移 < 2 m/s、姿态漂移 < 0.5° |
| 步长收敛 | dt 减半后关键指标变化 < 2%；导弹脱靶量变化 < 5% 或 < 2 m |
| 能量收支 | 60 s 内 `ΔE` 与 `∫gPs dt` 相对误差 < 1% |
| 公式对照 | 与解析解相对误差 < 5%（适用范围内） |
| 连续性 | 参数扫描相邻点的相对跳变 < 0.5% |
| 统计精度 | 概率类指标 95% 置信区间半宽 < 5 个百分点 |

## 2. 先修正或澄清的文档与公式问题

这些问题应在跑包线前处理，否则测试会把“定义错误”误判为“模型特性”。

### 2.1 跨声速零升阻力跳变

现定义只在 `M > 0.75` 加高斯项，导致 `M = 0.75` 处阻力系数突增约 28.46%。

**修改方案**（任选其一）：

- 对全部马赫数施加高斯项：
$$
C_{D0}(M)=C_{D0}\left[1+0.62\exp\left(-\left(\frac{M-1.05}{0.34}\right)^2\right)\right]
$$
该项在低马赫数已自然趋于零，无需分段；
- 或使用平滑过渡窗 `smoothstep(0.70, 0.80, M)` 乘高斯项。

**验证**：以 `ΔM = 0.001` 扫描 0.60–1.20，检查 `C_D0` 的一阶差分；修复后相邻点相对跳变应 < 0.5%，且加速度、`Ps` 不出现台阶。

**同时删除“该函数把极速限制在 Mach 2”这一结论**，改为由平衡求解得到的 `V_max(h)` 曲线来陈述。

### 2.2 诱导阻力系数的两个 `k`

文档中同时出现：

$$
C_{D_i}=\frac{C_L^2}{\pi\Lambda e}
\quad\text{与}\quad
D_i=\frac{n^2W^2}{q\pi\Lambda eS}
$$

前者系数无量纲，后者隐含的量纲为 `1/面积`。建议拆成两个命名并固定使用：

$$
k_c=\frac{1}{\pi\Lambda e}\quad(\text{无量纲}),\qquad
K=\frac{1}{q\pi\Lambda eS}\quad(\text{s}^2/\text{m}^2)
$$

则：

$$
C_{D_i}=k_cC_L^2,\qquad
D_i=K\,(nW)^2=\frac{n^2W^2}{q\pi\Lambda eS}
$$

**验证**：

- 数值上比较 `qS·k_c·CL²` 与 `K·(nW)²`，两者应相等（相对误差 < 1e-6）；
- 代码中所有 `k` 变量必须能追溯到上述两个定义之一；
- 修改 `S` 或 `q` 时，只有 `K` 变化，`k_c` 不变。

### 2.3 比能量与比剩余功率

$$
E=gz+\frac{V^2}{2}\ \text{(J/kg)},\qquad
H_E=z+\frac{V^2}{2g}\ \text{(m)}
$$

$$
P_s=\frac{(T-D)V}{W}\ \text{(m/s)},\qquad
\dot E=gP_s,\qquad \dot H_E=P_s
$$

**验证**：

- 能量审计：分别对 `E` 与 `g·H_E` 积分，检查是否一致；
- 若代码用 `E += Ps·dt` 更新，则量纲错误，应改为 `E += g·Ps·dt`；
- 文档中“`Ps<0` 表示当前状态无法维持”改为“在当前推阻条件下能量高度正在下降”，不推断唯一高度上限。

### 2.4 二自由度模型的定高约束

2DOF 固定 `γ=0` 时，水平平衡要求：

$$
n\cos\phi=1
$$

但控制接口允许独立给 `n` 与 `phi`。需要明确：

- 方案 A：定高模式强制 `n = 1/\cos\phi`，再叠加机动过载；
- 方案 B：允许 `\dot z = V\sin\gamma`，由垂直方程自然产生高度变化；
- 方案 C：保留人为定高，但文档标注“运动学演示”，且不与 3DOF 做定量对比。

**验证**：给定 `bank=60°`，检查：
- 方案 A 下高度漂移 < 10 m/min；
- 方案 B 下高度变化与 `V\sin\gamma` 一致；
- 任何方案下，`n\cos\phi ≠ 1` 时不得声称“水平定常盘旋”。

### 2.5 初始配平

当前“1 g 迎角 + 推力抵消零升阻力”只是近似。完整配平应满足：

$$
T-D_0-D_i=0,\qquad L=W,\qquad M_{\text{aero}}=0,\qquad \dot u=\dot w_b=\dot q=0
$$

**验证**：6DOF 在 9 km、巡航马赫、油门配平后静置 60 s，记录高度、速度、`theta`、`q`、舵面残差；若漂移超限，先修配平再跑包线。

### 2.6 推力矢量增升参数

需要明确同一工作状态下：

$$
C_{L,\max}^{\text{eff}}=C_{L0}+C_{L\alpha}\alpha_{\text{stall}}+\Delta C_L(\text{throttle},\text{ab})
$$

并说明基础 `CLmax=1.60` 与线性曲线失速点的关系。若 `CL0 + CLα·αstall = 1.60`，则 `+0.30` 得到 1.90；若 1.60 已是曲线截断值，才可能得到 1.80。文档必须给出复算路径。

**验证**：固定高度与速度，扫描 `throttle = 0, 0.62, 1.0` 与 `ab = 0, 1`，记录 `CLmax`、失速迎角、最大升力；检查是否与公式逐点一致。

### 2.7 坐标与符号

航向角负号不能只靠文字说明。需要：

- 定义世界系到机体系的旋转顺序（如 Z-Y-X）；
- 对 `(phi, theta, psi)` 与 `(p, q, r)` 做往返变换测试；
- 用已知机动检验符号：右滚、右转、抬头、正侧滑；
- 抽查 6DOF 与 3DOF 在同一 `(bank, n)` 下的转弯方向是否一致。

### 2.8 “概率”命名

在未校准前，把 `Pk` 称为“威胁评分”或“模型内命中评分”，不要直接称为真实命中概率。校准后再使用概率表述。

## 3. 代码级验证（不涉及飞行性能）

### 3.1 单元测试

| 测试 | 内容 | 判据 |
| --- | --- | --- |
| 大气 | 0/5/11/15/20/25/32 km 对照 ISA 表 | 密度/温度/压强误差 < 0.5% |
| 边界连续 | 11 km、20 km 两侧极限 | 相对跳变 < 0.1% |
| 气动系数 | `CL(α)`、`CD(M,CL)`、失速段 | 分段连续、单调区间正确 |
| 阻力等价 | 系数式与力式 | 相对误差 < 1e-6 |
| 推力 | 高度/马赫/军推/加力组合 | 与公式一致，误差 < 0.1% |
| 燃油 | 定推力耗油 | 与 TSFC 积分误差 < 0.5% |
| 过载 | `n_avail`、`n_sustain`、`n_tol` | 与解析式误差 < 1% |
| 导弹推进 | 燃烧时间、质量流、总冲 | 与参数表一致 |
| 引信 | 线段最近点 | 与解析最近距离误差 < 1e-6 |
| 裁判 | HP、越界、超时、同归于尽 | 分支全覆盖 |

### 3.2 不变量测试

- **质量守恒**：`m = m0 - 燃油 - 已发射导弹`，误差 < 1e-9；
- **能量审计**：`ΔE = ∫(T-D)V dt - ∫mg\dot z dt`（按模型定义）；
- **动量方向**：无侧滑时速度矢量与机体系 `x` 轴夹角等于 `α`；
- **角度范围**：`gamma ∈ [-80°,80°]`、`bank ∈ [-80°,80°]`、`alpha` 不越界；
- **限幅透明**：记录每步触发限幅的次数；若某包线点 50% 以上步数触发，结果标注“限幅主导”。

### 3.3 确定性测试

- 同 seed 运行两次，状态序列哈希一致；
- 不同 seed 但相同初始条件，统计量应落在置信区间内；
- 检查所有 `random` 调用是否由 episode seed 派生，禁止全局随机状态。

## 4. 飞机飞行包线测试

### 4.1 包线的解析基准

这些解析式用于确定测试点和判断数量级，不作为现实性能的唯一证据。

**平飞速度包线**（`n=1`）：

$$
T(V,h)=qSC_{D0}(M)+\frac{W^2}{q\pi\Lambda eS}
$$

- 低根为 `V_min`（受 `CLmax`/失速限制时用 `V_stall`）；
- 高根为 `V_max`（推力与阻力交点）；
- 若方程无解，则该高度不可平飞。

**失速速度**：

$$
V_{\text{stall}}=\sqrt{\frac{2W}{\rho SC_{L,\max}}}
$$

**维持过载与盘旋**：

$$
n_s=\sqrt{\frac{(T-qSC_{D0})\,q}{W^2K}},\qquad
\omega=\frac{g\sqrt{n_s^2-1}}{V},\qquad
R=\frac{V}{\omega}
$$

**瞬时盘旋**：取 `n = min(9, n_lift)`，同上计算 `ω`、`R`，并记录 180° 时间与能量损失。

**爬升率**：

$$
\text{ROC}\approx P_s=\frac{(T-D)V}{W}
$$

**升限**：`max_h Ps_max(h) = 0`（实用升限可取 `Ps_max = 0.5 m/s`）。

**能量高度**：

$$
H_E=z+\frac{V^2}{2g}
$$

## 5. 导弹飞行包线测试

### 5.1 定义

| 指标 | 定义 |
| --- | --- |
| `R_max` | 给定高度、双方速度、目标机动下，命中率 ≥ 0.5 的最远发射距离 |
| `R_min` | 命中率 ≥ 0.5 的最近发射距离 |
| `NEZ` | 目标做最大规避机动时仍能以 ≥ 0.9 命中率命中的最远距离 |
| `AOR` | 允许发射的离轴角范围（受导引头/万向支架限制） |
| `T_flight` | 发射到起爆/脱靶的时间 |
| `d_miss` | 最近接近距离 |

`R_max`、`NEZ` 必须由**弹道积分 + 引信判定 + 蒙特卡洛**得到，不能只由评分公式给出。

| M09 | 导引头视场/锁定 | 0–90° 离轴，3/9/15 km | 锁定时间、丢锁 | 超出视场不锁定；边界误差 < 2% |

| M11 | ARH 截获 | RCS=0.1/0.5/1.2/5 m² | 截获距离 | 距离按 `RCS^0.25` 缩放，误差 < 5% |
| M12 | 干扰物 | 箔条/热诱弹，notch=0/0.5/1 | 诱骗率、脱靶量 | 横转时箔条有效；迎头/尾追时显著下降 |
| M13 | 引信与杀伤 | `d = 0, R/2, R, 1.2R` | `Pk(d)`, 伤害 | 曲线单调；120 Hz 下无穿透；边界连续 |
| M14 | 末段能量 | 低空/高空、远距发射 | 末速、`qbar`、`a_axis_max` | 低动压时正确失控；不出现无限机动 |
| M15 | 齐射与在飞限制 | 双发/四发 | 在飞数、命中分布 | 不超限发射；结果可复现 |
| M16 | 步长与统计收敛 | dt=1/60,1/120,1/240；N=100/1000 | `d_miss`, `Pk` | 脱靶量变化 < 5%；Pk 置信区间半宽 < 5% |

### 5.3 概率校准

将文档中的评分曲线 `Pk(d, aspect)` 与实际蒙特卡洛命中频率做可靠性图：

- 横轴：模型评分分箱（0–0.1, 0.1–0.2, …）；
- 纵轴：该分箱内实测命中频率；
- 指标：Brier 分数、期望校准误差 ECE、95% 置信区间。

若校准差，只有两个诚实选择：

1. 把该数值改名为“威胁评分”，不解释为概率；
2. 用测试数据重新拟合曲线，并明确其适用范围。

## 6. 模型对比与策略归因

### 6.1 3DOF 与 6DOF 的可比条件

只在以下条件比较：

- 协调飞行（`β≈0`）；
- 非失速（`α < αstall`）；
- 无强限幅；
- 同一初始能量高度；
- 同一控制指令序列。

比较指标：`ω`、`R`、`H_E` 损失、达到 90° 转向的时间。若差异 > 10%，先检查配平、舵面增益与坐标符号，而不是直接归因于“6DOF 更真实”。

### 6.2 机型与策略分离的因子实验

至少做 2×2 因子设计：

| 组 | 机体参数 | 策略参数 |
| --- | --- | --- |
| G1 | Su-57 | Su-57 策略 |
| G2 | Su-57 | F-16V 策略 |
| G3 | F-16V | Su-57 策略 |
| G4 | F-16V | F-16V 策略 |

- 每组做镜像对抗（交换初始方位）；
- 每组 ≥ 30 个 episode seed；
- 报告胜率及 95% 置信区间；
- 使用方差分析或混合效应模型分离机体、策略、交互项；
- 若不能分离，结论只能写“该配置组合的结果”，不能写“某机型更强”。

### 6.3 策略消融

对关键机制逐一关闭：

- 关闭能量保护；
- 关闭 G 耐受；
- 关闭导弹防御分档；
- 关闭交汇方案；
- 关闭防抖/最短驻留；
- 关闭 NEZ 发射门限。

比较胜率、平均交战时间、发射数、命中率、能量终值。消融应显示“机制是否按设计起作用”，而不是只展示最终胜负。

## 7. 复现性与数值收敛

### 7.1 复现性

- 每个 episode 的 seed 同时决定：开局方位、引信随机、诱骗随机；
- 禁止依赖全局随机状态或墙钟时间；
- 同 seed 输出状态哈希；
- 记录 Python/依赖版本、参数文件哈希、提交号。

### 7.2 步长收敛

对关键场景做 dt 减半：

- 平飞配平 60 s；
- 9 g 盘旋 180°；
- 导弹迎头 20 km 拦截；
- 近距 3 km 红外弹发射；
- 箔条诱骗。

绘制关键指标随 dt 的变化曲线。若 1/120 与 1/240 差异 > 2%，说明当前步长不足或限幅主导，需要在文档中标注。

### 7.3 限幅统计

记录每步触发以下限幅的次数：

- 速度下限；
- `cosγ` 下限；
- 过载上下限；
- 迎角/失速限制；
- 导弹动压/过载失效。

若某测试中限幅触发比例 > 30%，该点的结论应标为“保护逻辑主导”，不能作为模型自然性能。

## 11. 结论

对当前系统，最合适的验证顺序是：

1. 先把公式定义和量纲问题修到可复算；
2. 用解析解和单元测试证明“代码算的是文档写的”；
3. 用飞机与导弹包线图找出模型边界和限幅主导区；
4. 用步长收敛与蒙特卡洛证明数值和统计稳定；
5. 最后才讨论现实有效性，并且必须依赖独立数据。

包线测试的作用不是给模型“背书”，而是把它的适用范围、失效边界和参数敏感性画出来。只有这些图与日志齐全时，“模型内结果”才是一个有信息量的结论。
