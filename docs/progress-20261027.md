# 2026-10-27 进展记录

## 一、今日实现的功能

### 1. 开局占位（不再直线对头）
- 新增 `POSITION` 原语：开局阶段双方按各自机体能力侧向偏置 8°–20°，并分别选择爬升/俯冲方向。
- 距离进入 `OPENING_DIST = 5000 m` 后自动转入正常接敌，避免一开局就形成固定对头。
- 站位对换镜像实验时，机体参数与 Agent 个性作为整体一起换边。

### 2. 被锁定后的择机防御
- 新增 `_should_defend` 决策：只有在“对方仍有弹、对方锁定进度 ≥ 85%、自身速度余量足够、且自己不在更优进攻位”时才进入防御。
- 若自己已锁定对方且导弹仍在发射包线内，则优先完成发射而不是立刻规避。
- 实测 501 次“被锁定且距离 < 8 km”的决策中，499 次选择防御、2 次继续进攻。

### 3. 提前的导弹威胁响应
- `MISSILE_EVADE_DIST` 提升到 9000 m，来袭弹进入 9 km 即启动规避。
- 分距离策略：4.5 km 以外用 `BEAM` / `SPLIT_S` 消耗导弹能量，进入 4.5 km 内才使用 `BREAK` / `BARREL` 等硬甩动作。

### 4. 多样化防御机动 + 能量纪律
- 防御机动库：`BEAM`、`BREAK`、`SPLIT_S`、`BARREL`、`SCISSORS`、`IMMELMANN`、`LOOP`，每 3 s 轮换一次，并按能量、高度余量过滤不可用动作。
- 针对防御中能量崩溃问题做了四项修复：
  - 进入防御时锁定转向方向 `_def_sign`，仅当方位差 > 60° 才翻转，消除左右抖动；
  - 新增 `_level_cap`，按实际坡度限制竖直过载，消除“坡度回中却仍拉正过载”导致的意外爬升；
  - 防御中增加爬升保护：航迹角 > 25° 且速度不足 1.7 倍失速速度时强制 `SPLIT_S`；
  - 低能量时强制俯冲卸载；9 km 外的防御轮换中移除 `IMMELMANN` / `LOOP` 等爬升类动作。
- `Observation` 新增 `own_bank`，供战术层判断当前坡度。

### 5. 录制与全局轨迹图
- `render.py`：`Renderer(follow=..., follow_dist=...)` 支持跟随相机，机尾后方跟拍、`yaw = psi + π`、俯角约 16°。
- `main.py` 新增：
  - `_sample_state()`：记录采样时刻的位置、机头方向、机翼方向；
  - `save_trajectory_plot()`：三维全局轨迹图，整条航迹 + 定时采样点 + 机头箭头 + 机翼短线 + 时间标注 + 高度投影；
  - `run_record()`：无窗口渲染并写入 mp4，同时按固定间隔采样轨迹；
  - CLI 参数 `--record`、`--track-plot`、`--follow`、`--track-interval`、`--fps`。
- 轨迹图用颜色（viridis）编码采样时刻，SU-57 用圆点、F-16V 用三角，便于同时区分机型和时刻。

## 二、验证结果

- 2DOF / 3DOF / 6DOF 三种内核均可正常跑完，无异常退出。
- 12 局镜像矩阵校验通过：站位对换后胜者跟随机体，结果一致。
- 开局横向间距约 1.36 km、高度差约 855 m，已实现侧向错开。
- 防御修复后 SU-57 防御期间速度维持 211–247 m/s、航迹角约 ±8°，不再失速或冲高。
- 本次 300 s 上限的对局在 **204.71 s** 结束：SU-57 以机炮击落 F-16V（红方胜），SU-57 剩余 HP 110、弹药 65 发；全场机炮开火 85 次、格斗弹发射 8 枚但 0 命中（9 km 提前规避效果明显，末端制导/能量仍是待优化项）。
- 录制参数：1280×800、H.264、20 fps，成片时长 204.75 s、大小约 42 MB；轨迹图每 10 s 采样一次，双方各 21 个姿态采样点。

## 四、下一步工作方向

1. **导弹末端制导与能量优化**：9 km 提前规避后当前命中率偏低，需检查末端比例导引增益、舵面可用过载与推进剂能量模型，并优化战术层发射时机（高离轴角不发射、等目标能量衰减后再补射）。
2. **威胁评估与防御决策的代价模型**：把“防御消耗的能量/高度”与“被命中的期望伤害”量化，替代当前基于阈值的规则，减少无效规避。
3. **编队与协同对抗**：扩展到 2v2，加入僚机分工（压制、诱饵、补射）与共享锁定信息。
4. **轨迹回放与自动复盘**：基于本次的采样数据输出关键事件时间线（首次锁定、首次发射、防御触发、命中/脱靶原因），便于定位战术退化。
5. **后续将加入过失速机动**：引入大迎角/过失速区的升力与阻力模型、推力矢量控制与姿态快速指向，使 Su-57 在近距缠斗中具备“先指向、后机动”的能力，并配套相应的战术原语与能量风险约束。
6. **6DOF 飞行品质与控制律完善**：在保留 3DOF 作为主验证内核的前提下，逐步修正 6DOF 的配平、阻尼与舵面速率限制，为过失速机动提供执行基础。
